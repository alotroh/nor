# NØR — промпты для генерации изображений (ChatGPT / GPT-4o image)

Все изображения должны выглядеть как **одна кампания**: холодная, сдержанная,
архитектурная, дорогая. Один мир, одна цветокоррекция, один свет.

---

## 0. КАК ПОЛЬЗОВАТЬСЯ (важно)

1. Открой новый чат в ChatGPT (модель с генерацией изображений).
2. **Первым сообщением** прикрепи файл `public/img/hero.png` (наш герой) и вставь
   блок «SETUP» ниже. Это задаёт модель, свет и стиль — дальше всё будет
   консистентным.
3. Дальше кидай промпты по одному. В каждом уже «зашита» отсылка к общему стилю.
4. Проси нужный формат кадрирования (в конце каждого промпта указано:
   *portrait / square / landscape*).
5. Скачивай, переименовывай по схеме из раздела 7 и клади в `public/img/`.

> Требование ко всем изображениям: реалистичная фотография, без текста, без
> логотипов, без водяных знаков, без брендинга на одежде. Никаких лиц крупным
> планом с искажениями — модель может быть в профиль / со спины / обрезана.

## 1. SETUP (первое сообщение, приложи hero.png)

```
Ты — фотограф fashion-кампании. Я делаю лукбук вымышленного бренда NØR,
осень/зима 2026. Прикреплённое фото — эталон стиля и модели: тот же молодой
мужчина (тёмные вьющиеся волосы), та же холодная пасмурная атмосфера, тот же
брутализм из бетона, тот же приглушённый чёрно-угольно-бетонный колорит,
кинематографичный естественный свет, лёгкое зерно плёнки, матовые фактуры.

Во всех следующих изображениях сохраняй ЭТОТ мир, свет и цветокоррекцию.
Реалистичная редакторская фотография, без текста и логотипов. Одежда
преувеличенно oversized, архитектурные силуэты, только чёрный / угольный /
костяной / бетонный цвета. Подтверди, что готов, и жди промпты по одному.
```

## 7. КУДА КЛАСТЬ ФАЙЛЫ И КАК ПОДКЛЮЧИТЬ

Скачанные картинки переименуй и положи в `public/img/`:

```
public/img/object-001-1.jpg … object-006-4.jpg   (24 файла)
public/img/look-01.jpg … look-12.jpg              (12 файлов)
public/img/material-01.jpg … material-03.jpg      (3 файла)
public/img/intro.jpg  story.jpg  editorial.jpg
```

Потом в `src/data/products.ts` у каждой картинки просто добавь `src`:

```ts
images: [
  { src: '/img/object-001-1.jpg', alt: '…', crop: 'full',   tone: 1 },
  { src: '/img/object-001-2.jpg', alt: '…', crop: 'detail', tone: 2 },
  { src: '/img/object-001-3.jpg', alt: '…', crop: 'macro',  tone: 0 },
  { src: '/img/object-001-4.jpg', alt: '…', crop: 'profile',tone: 1 },
]
```

Аналогично `lookbook` (`src: '/img/look-01.jpg'` …) и материалы в
`src/components/Materials.astro`. Как только у картинки есть `src` —
процедурная «заглушка» автоматически заменяется на фото. Layout менять не нужно.

> Совет: держи одинаковую цветокоррекцию. Если ChatGPT «уводит» цвет — добавляй
> в промпт: «холоднее, темнее, приглушённее, как на референсе».
